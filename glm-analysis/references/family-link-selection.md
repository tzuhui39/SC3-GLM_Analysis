# 依反應變數型態選擇 family / link 的判斷邏輯

## 總原則：這只是建立候選模型的起點

依反應變數型態選擇 family/link，是建立**候選模型**的起點，不代表僅憑 Y 的直方圖、偏態或整體平均數與變異數，就能確認分布假設成立。應同時考慮研究問題、觀測值的獨立性、資料產生機制、解釋變數與反應變數的條件關係，以及配適後的診斷結果。若有多個合理候選模型，應保留並比較，而不是在配適前就宣稱某一個模型必然正確。

進入 Stage 2 時依下面的順序處理，每一步都對照使用者的反應變數 Y 實際去看資料（`table(y)`、`summary(y)`、直方圖），不要只憑變數名稱猜。

## 第零步：先辨識資料結構與特殊情況

在選 family 之前，先確認下列情況是否存在，有的話要先和使用者討論，再決定能不能直接套用一般 GLM：

- **相關觀測**：重複測量、同一個人／家庭／學校／地區的多筆資料、時間序列、空間群聚。一般 GLM 假設觀測獨立，不成立時標準誤與 p 值會失真。可能需要 GLMM、GEE 或其他方法，**這些超出本 skill 的支援範圍**，要明確告知使用者，不要假裝一般 GLM 已經處理好。
- **暴露量不同（offset）**：計數資料若各觀測的觀察時間、人年數、面積、人口數不同，要先確認是否需要 `offset(log(暴露量))`。忽略暴露量差異，模型回答的就不是想問的問題（例如把「次數」當成「率」）。
- **0 與 1 的邊界值、極端稀有事件、完全分離的跡象**：二元資料若某個變數幾乎完全決定 Y，要先辨識，見 `model-building-and-validation.md` 的 F 節。

## 決策流程

**第一步：先看 Y 是離散（二元、計數、類別）還是連續。** 以下每一類都是「初步候選」，後續仍須依診斷結果確認。

### A. 單筆二元資料（每筆觀測是 0/1）

- **family**：`binomial`（每筆是一次 Bernoulli 試驗）
- **link**：`"logit"`（預設、最常用，係數是 log-odds，`exp(coef)` 是 odds ratio）
- 其他可選連結：
  - `"probit"`：假設潛在常態分佈時使用，係數較難直覺解釋
  - `"cloglog"`：Y=1 的機率很小、且想強調「事件發生的風險」時
- Odds ratio 不是風險比，也不能直接說成「機率增加幾倍」；事件常見（機率不小）時兩者差距可能很大。

### B. 成功次數／失敗次數（分組 binomial）

- 每個觀測單位有**已知的試驗總數**（例如 10 次中 3 次成功），用 `cbind(成功數, 失敗數)` 當作反應變數：`glm(cbind(success, failure) ~ ., family = binomial, data = dat)`
- link 預設 `"logit"`
- 這種資料可能出現組間額外變異（過度離散），過度離散檢查有意義，見 `diagnostics-checklist.md`。

### B2. 只有「比例」的資料

- **只有比例值、沒有成功次數與總試驗數**：不能直接假設它是一般 binomial 資料。要先和使用者確認比例的產生方式與分母資訊。若能還原成「成功數／總數」，就當成 B 類處理。
- **連續比例（例如介於 0 與 1 之間的測量值）**：通常需考慮 beta regression 或其他適當的比例模型；若資料含有精確的 0 或 1，還需要適當的擴展模型。這些超出本 skill 的支援範圍，要告知使用者，不要硬套 binomial。

### C. 非負整數計數資料

- **family**：`poisson`，**link**：`"log"`（`exp(coef)` 是 rate ratio）
- Poisson 的假設是：**給定解釋變數後**，條件平均數與條件變異數相等。不能只比較整體 Y 的平均數與變異數，兩者接近不代表假設成立，兩者差很多也可能只是因為 X 造成平均數的變化。要在配適後用模型的殘差與離散程度來檢查（見 `diagnostics-checklist.md` 第 2 節）。
- 發現過度離散時，有兩個**不完全等價**的處理方向，不要只憑一個離散比值就自動選其中一個：
  - `quasipoisson(link = "log")`：保持 Poisson 的平均數結構，以離散參數調整標準誤與推論。沒有真正的概似函數，不能用 AIC，推論要用適合準概似的方法（例如 F 檢定）。
  - `MASS::glm.nb()`：負二項迴歸，採用不同的條件變異數結構並估計額外的離散參數，有概似函數，AIC 可比較。
  - 兩者都不會自動修正錯誤的平均數結構、遺漏變數、相依性或其他模型錯置。換了 family 之後要重新檢查殘差與配適，不能假設問題已解決。
- 若有 offset（暴露量不同）、重複測量、群聚結構，或 0 的生成機制特殊，可能需要其他模型架構，先辨識再決定是否還在支援範圍內。
- 若 0 比模型預期多，依 `diagnostics-checklist.md` 第 7 節檢查，並說明零膨脹與門檻模型的概念差異。**本 skill 只負責到判斷並說明兩種模型的區別為止，不支援這兩種模型的配適、診斷與解釋**，要誠實告知使用者這個限制。

### D. 連續、嚴格為正的資料（例如金額、時間長度）

- 初步候選：`Gamma`，**link** 常用 `"log"`（係數解釋成倍數效果，且是在其他變數固定下），或 `"inverse"`（canonical link，較難解釋）
- 「直方圖右偏」本身不足以證明該選 Gamma。要一起考慮：研究問題、正值資料的產生機制、條件變異數是否隨條件平均數增加（約與平均數平方成比例）、與其他合理候選（例如對 Y 取 log 後的 Gaussian 模型、其他分布）的配適比較。
- Y 含 0 或負值時 Gamma 不適用（要求嚴格為正），要先和使用者確認資料或考慮其他模型。

### E. 連續資料，條件分布大致對稱

- 初步候選：`gaussian` + `"identity"`
- 重點不是 Y 的直方圖是否對稱，而是**給定解釋變數後**，平均數結構是否合理、殘差是否沒有明顯的系統性型態、變異是否大致穩定。
- 老實告知：`glm(family = gaussian)` 在數學上等同於 `lm()`。沒有特殊理由時可以直接用 `lm()`，但使用者要求 GLM 框架（例如作業要求）就用 `glm()` 並說明兩者等價。

## 快速對照表（初步候選，不是最終判定）

| 反應變數型態 | 初步候選 family | 常用 link | 係數轉換後的意義 |
|---|---|---|---|
| 單筆二元 0/1 | binomial | logit | odds ratio（`exp(coef)`） |
| 成功數／失敗數（已知總數） | binomial (cbind) | logit | odds ratio |
| 非負整數計數 | poisson | log | rate ratio（`exp(coef)`） |
| 計數且條件變異大於平均 | quasipoisson 或 MASS::glm.nb | log | rate ratio |
| 連續、嚴格為正 | Gamma | log 或 inverse | 倍數效果（log link，其他變數固定） |
| 連續、條件分布大致對稱 | gaussian | identity | 原始尺度的效果 |

## 給使用者的說明範例語氣

「因為反應變數 Y 是計數資料（非負整數，值域從 0 到 47），所以先把 `poisson(link = "log")` 當作候選模型。這只是起點：Poisson 假設的是『在解釋變數固定時，平均數等於變異數』，要等模型配適完，才能用殘差與離散程度檢查這個假設是否合理。如果發現不合理，我們再比較負二項等其他候選。」
