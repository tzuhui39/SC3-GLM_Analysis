# 建模流程補充：研究目的、函數形式、選模、預測評估、結論一致

這份參考檔涵蓋建模時的判斷規則，在 SKILL.md 對應的階段會要求先讀取。程式碼只在背景執行，不要貼到對話回覆中（除非使用者要求）。

## 總原則：證據不是自動決策規則

1. 不得僅憑單一圖形、檢定 p 值或經驗門檻，自動宣告模型正確、錯誤或必須更換。
2. 每項結果都要結合資料結構、研究目的、模型假設及其他證據解釋。
3. 若有多個合理模型，說明各自的優缺點、選模依據與限制；不得只因某模型的 p 值較小、AIC 較低或係數較容易解釋，就宣稱它是唯一正確的模型。
4. 更換 family、link、函數形式或變數組合後，要重新配適並重新執行相關診斷。
5. 證據不足時，明確說明不確定性，不要強行給出確定的結論。

## A. 研究目的與時間順序（Stage 1-0 使用，配適模型之前）

先問清楚研究目的，因為它決定怎麼選變數、選模型、評估：

| 研究目的 | 重點 | 對後續的影響 |
|---|---|---|
| 解釋關聯 | 描述 X 與 Y 的關係與強度 | 係數的解釋是重點；措辭一律用「關聯」，不用因果語氣 |
| 建立預測模型 | 對新資料預測 Y | 必須做樣本外驗證（見 D）；只能使用「預測當下能取得」的變數，避免使用未來資訊（資料洩漏） |

**對每個可疑的解釋變數，分別釐清四件事**（「記錄在結果之後」與「變數本身在結果之後才產生」並不相同）：

1. 變數實際發生或存在的時間。
2. 變數被測量或記錄的時間。
3. 變數是否可能受到 Y 影響。
4. 研究目的是解釋關聯，還是預測。

例如：某個背景特徵早就存在、只是事後才被記錄，通常不是問題；而事後才發生的花費、治療或結果，則可能受 Y 影響。處理方式：

- 把可疑變數與四項資訊列給使用者，詢問並確認，**不要自行決定排除或保留**。
- 預測：關鍵是預測時點是否取得得到該變數。
- 保留可疑變數時，在結論中說明可能造成的偏誤。

**本 skill 不做因果推論。** 結果一律以「關聯」描述，不使用「導致」「處理效果」「影響了」等因果措辭。使用者的研究目的是因果推論時，要明講這個限制：本 skill 只能描述 X 與 Y 的關聯（或建立預測模型），因果推論需要另外的設計與方法，請使用者改用專門的工具。

## B. 連續變數的函數形式（Stage 3，配適候選模型之前）

連續解釋變數在 link scale 上與 Y 的關係是否線性，需要檢查，但**預設只配適一個模型**：用圖形與領域知識決定這個模型用什麼形式，沒有明顯非線性證據就用線性。不要一開始就把線性、log、多項式、樣條都跑一遍，避免模型數量膨脹、或變成「嘗試很多形式再挑最好看的」。下面第 2 到 4 點的形式比較，只在 (1) 使用者要求，或 (2) 圖形、診斷（偏殘差圖、殘差對該變數作圖）已顯示非線性證據時才做。

1. **先用圖形與領域知識判斷線性是否合理。** 分組趨勢圖（二元 Y 用經驗 logit，計數或連續正值 Y 用 log 平均數）只能提供線索，**不能只憑分組圖決定轉換方式**，因為它受分組方式影響、且隱藏組內變異。
2. **對有非線性證據的變數**（圖形或領域知識顯示可能非線性），才挑**少數事先有理由的候選形式**（例如線性、`log()`、二次項或樣條各一種），不要對每個變數都把所有形式全部跑一遍。
3. **巢狀的候選形式用概似比檢定**（例如線性對樣條）；非巢狀的候選形式（例如 `log(x)` 對線性）用 AIC／BIC 輔助比較。
4. **同時看實質改善**：複雜形式是否真的改善配適與預測，而不是只看單一 p 值。
5. **偏殘差圖**（`car::crPlots(model)`）可作為輔助線索，但不是所有 GLM 都適用的標準或唯一工具，使用前確認它適用於當前的模型型態，並理解它的圖形解讀；它不能單獨決定函數形式。
6. **選模若屬探索性過程，要在報告中說明**，選模後的 p 值與信賴區間不能解讀成完全未經選擇的確認性推論。
7. 變數含 0 時，`log(x)` 會出問題。**不要直接把 `log(x + 常數)` 當成預設補救方式**：加上的常數會改變變數的函數形式，常數相對於原始數值很大時，可能明顯改變模型描述的關係。先釐清 0 的意義：是真正沒有該特徵，還是低於測量或記錄門檻？再決定處理方式（例如加一個「是否為 0」的指標變數搭配 log 的正值部分、改用樣條、分段，或在有理由時使用 `log(x + c)` 並做常數的敏感度檢查），並向使用者說明選擇的理由。

```r
# 分組趨勢：計數／連續正值 Y 用 log 平均數（二元 Y 改成經驗 logit）
dat$grp <- cut(dat$x, quantile(dat$x, seq(0, 1, .1), na.rm = TRUE), include.lowest = TRUE)
emp <- dat |> dplyr::group_by(grp) |>
  dplyr::summarise(x_mid = median(x), mean_y = mean(y), n = dplyr::n())
emp$log_mean <- log(emp$mean_y + 0.5)
# 二元 Y：p <- mean(y); elogit <- log((p * n + 0.5) / ((1 - p) * n + 0.5))

# 對有疑慮的變數，比較少數候選形式（以 poisson 為例）
m_lin <- glm(y ~ x + z, family = poisson, data = dat)
m_log <- update(m_lin, . ~ . - x + log(x))
m_spl <- update(m_lin, . ~ . - x + splines::ns(x, df = 3))
anova(m_lin, m_spl, test = "Chisq")     # 線性與樣條是巢狀
AIC(m_lin, m_log, m_spl); BIC(m_lin, m_log, m_spl)
```

## C. 系統性比較候選模型與選模原則（使用者要求比較，或診斷後需要調整模型時）

**預設只配適一個模型（m1）**，不要一開始列出多個候選模型，目的是避免「試很多模型再挑最符合預期的」。這是預防盲目選模的規則，**不是限制分析的硬性規定**。進入比較的情況有三種：(1) 使用者明確要求比較多個模型；(2) Stage 4 診斷出現證據顯示 m1 有問題，提出調整後的 m2；(3) 研究問題本身就涉及要比較的結構（例如本來就要檢驗線性與非線性關係、或有充分理論依據的幾個模型），這時**事先**說明理由並用勾選框問使用者要不要一起比較，不必等到診斷出問題。比較哪些模型要在看結果之前決定。下面的規則在這些情況下適用。

1. **先列出候選模型並編號**（m1、m2、…），每個簡述差異（加了哪些變數、哪種函數形式、是否含交互作用、哪個 family）。
2. **在看結果之前，先和使用者講好選模原則**，並把不同證據分開看，不要混成同一套排名：
   - **概似比檢定（LRT）**：只用於適當條件下可比較的**巢狀**模型，檢驗新增參數是否帶來統計上的改善。
   - **AIC／BIC**：在使用相同反應資料、可比較的概似模型等適當條件下，比較配適與複雜度的取捨；數值較小通常較受支持，但不代表模型已被證明正確。預測偏重 AIC，簡約解釋偏重 BIC，兩者結論不同時依研究目的決定。
   - **殘差診斷與研究合理性**：判斷模型是否仍有系統性問題、函數形式是否合理。
   - **樣本外預測評估**：研究目的是預測時，驗證資料上的表現是主要證據之一。
   - 差距很小（例如 AIC 差小於 2）時，優先考慮較簡單、較合理的模型。
3. **所有候選模型必須使用相同的分析樣本。** 若各模型因變數缺失值而使用不同的觀測筆數，AIC、BIC 與 LRT 的比較不再公平或不適用。要用 `nobs()` 確認，必要時先把資料限縮到所有候選模型共同的完整個案，或明確說明因樣本不同造成的限制。
4. `quasipoisson`／`quasibinomial` 沒有概似函數，不能用一般的 AIC 或標準概似比檢定。
5. **用一張表並排呈現**：模型、觀測數、迴歸係數個數、額外估計的分布參數個數（例如 `glm.nb` 的 θ 算 1 個，Poisson 為 0）、收斂狀況、AIC、BIC、殘差偏差，並附 LRT 結果。不要把「迴歸係數個數」直接標成整個模型的參數個數，否則會低估負二項等模型實際估計的參數。
6. **不要因為某個模型的係數比較容易解釋，就忽略明顯的配適不足。** 若較簡單的模型配適明顯較差，要如實告知，由使用者決定是否仍保留，並在結論中說明簡化的目的與配適限制。
7. 選定最終模型後，後續所有解釋、診斷、預測與結論都以它為準（見 E）。

```r
ms <- list(m1 = m1, m2 = m2, m3 = m3)
cmp <- data.frame(
  模型 = names(ms),
  觀測數 = sapply(ms, nobs),
  迴歸係數個數 = sapply(ms, function(m) length(coef(m))),
  額外分布參數 = sapply(ms, function(m) if (inherits(m, "negbin")) 1 else 0), # glm.nb 的 theta
  收斂 = sapply(ms, function(m) isTRUE(m$converged)),
  AIC = sapply(ms, AIC),
  BIC = sapply(ms, BIC),
  殘差偏差 = sapply(ms, deviance),
  row.names = NULL
)
knitr::kable(cmp, digits = 1)
anova(m1, m2, test = "Chisq")   # 只用於巢狀模型
```

## D. 模型診斷與預測評估要分開（Stage 4）

- **模型診斷**：檢查假設與配適問題（見 `diagnostics-checklist.md`）。診斷通過，不代表對新資料預測得好。
- **預測評估**：用**樣本外**資料評估。同一批資料上算出的 pseudo-R²、AUC 等是樂觀的，不能當作預測能力。兩者不能互相取代。

**做法與規則**：

1. **切分方式要配合資料結構**，不能一律用隨機 k 折。**所有候選模型使用相同的折**才公平。
   - 一般獨立觀測：k 折交叉驗證（k = 5 或 10）；資料量大時可用訓練／測試切分。
   - **時間序列或有時間順序的資料**：用時間順序切分（以過去預測未來），不可用一般隨機 k 折，否則會用未來資料預測過去。
   - **群聚或重複測量資料**（同一受試者、家庭、學校有多筆）：依預測目標，以群組為單位切分，同一群組不可同時出現在訓練與驗證資料。
   - 資料有群聚、時間順序等結構時，本 skill 的一般 GLM 本身就可能不適用（見 `family-link-selection.md` 的第零步），要先告知使用者。
2. **二元資料用分層切分**，目的是讓每一折都盡量有兩個類別，**但分層不保證每折都有正例**：少數類別的觀測數少於折數時，即使分層也辦不到。先檢查各類別的樣本數，依資料量調整折數；仍無法合理分折時，明講限制，不要假設分層已解決問題。否則 AUC 在缺類別的折裡無法計算。分層仍要遵守上一點：同一受試者或群組不可同時出現在訓練與測試資料。
3. **指標彙整方式要明確定義**：本流程採用「**彙整所有折的樣本外預測（out-of-fold）後，一次計算指標**」作為主要結果；若同時報告各折的指標，要說明那是各折的平均或變動範圍，兩者不一定相等。
4. 每一折要檢查配適是否成功，並**分別記錄**警告、錯誤、是否收斂與預測是否成功：只有警告的折，預測保留但要回報警告內容（例如擬合機率為 0 或 1 通常暗示分離，由使用者判讀）；錯誤、未收斂或預測失敗（例如驗證折出現訓練折沒有的類別水準）才算該折失敗。失敗的折與失敗原因要回報，不能默默忽略，也不要把所有警告一律當成失敗。
5. **避免資料洩漏**：若流程包含缺失值處理、插補、標準化或其他依資料估計的前處理，必須在**每一折內只用訓練資料估計，再套用到驗證資料**，不能先用整份資料估計。
6. 指標依 Y 的型態選擇：

| Y 的型態 | 建議指標 |
|---|---|
| 二元 | AUC（區辨能力）、Brier score、log loss（樣本外對數概似，嚴格的機率評分），並搭配**校準**評估（這些都不能取代校準）。不要只看分類準確率 |
| 計數／連續 | 樣本外平均偏差（mean deviance）或對數概似、RMSE、MAE；依預測目標選擇適合的誤差指標 |

不能把訓練資料上的配適程度（樣本內 AUC、pseudo-R²）當成樣本外預測表現。

7. **加入基準模型一起比較**：基準模型（例如只有截距的模型）也用同一組折、同一個指標計算樣本外表現，讓表格的每一列都能用同一指標比較，不要有的列是 NA。基準模型的表現告訴使用者「完全不用解釋變數」能做到什麼程度，候選模型要贏過它才有意義。

研究目的是預測時，樣本外評估是必做項目。研究目的是解釋關聯時，**不需要**為了選出預測表現最好的模型而套用交叉驗證選模，預測表現最佳的模型也不一定最適合回答係數的解釋問題；這時只要明講「診斷通過不等於預測能力良好」，視需要補做。

下面是教學用的穩健範例，不是適用於所有 GLM 的正式驗證程式，遇到特殊資料要再調整：

```r
# 分層（二元）或隨機（其他）切分；少數類別觀測數少於折數時，自動降低折數並提示
make_folds <- function(y, k = 5, seed = 1) {
  set.seed(seed)
  if (all(y %in% c(0, 1))) {
    n_min <- min(table(y))
    if (n_min < k) { k <- max(2, n_min); message("少數類別只有 ", n_min, " 筆，折數降為 ", k, "；若仍不足以分折，請說明限制") }
    fold <- integer(length(y))
    for (v in c(0, 1)) { idx <- which(y == v); fold[idx] <- sample(rep(1:k, length.out = length(idx))) }
  } else fold <- sample(rep(1:k, length.out = length(y)))
  fold
}

# 回傳樣本外預測與每一折的記錄：警告、錯誤、是否收斂、預測是否成功分別記錄
# 只有「錯誤、未收斂或預測失敗」才視為該折失敗；只有警告時保留預測並記錄警告內容，由使用者判讀
cv_oof <- function(formula, data, family = NULL, fold, fitter = glm) {
  k <- max(fold); oof <- rep(NA_real_, nrow(data))
  log <- data.frame(折 = 1:k, 錯誤 = "", 警告 = "", 收斂 = NA, 預測成功 = NA)
  for (i in 1:k) {
    tr <- data[fold != i, , drop = FALSE]; te <- data[fold == i, , drop = FALSE]
    w <- character(0)
    m <- tryCatch(withCallingHandlers(
      if (is.null(family)) fitter(formula, data = tr) else fitter(formula, family = family, data = tr),
      warning = function(x) { w <<- c(w, conditionMessage(x)); invokeRestart("muffleWarning") }),
      error = function(e) { log$錯誤[i] <<- conditionMessage(e); NULL })
    log$警告[i] <- paste(unique(w), collapse = " | ")
    if (is.null(m)) { log$預測成功[i] <- FALSE; next }
    log$收斂[i] <- isTRUE(m$converged)
    p <- tryCatch(predict(m, newdata = te, type = "response"),
                  error = function(e) { log$錯誤[i] <<- conditionMessage(e); NULL })
    log$預測成功[i] <- !is.null(p) && isTRUE(m$converged)
    if (log$預測成功[i]) oof[fold == i] <- p
  }
  list(pred = oof, log = log, failed_folds = sum(!log$預測成功), warned_folds = sum(log$警告 != ""))
}

# 彙整後的指標：計數／連續 Y
cv_metrics <- function(y, mu, family) {
  ok <- !is.na(mu)
  c(mean_dev = mean(family$dev.resids(y[ok], mu[ok], rep(1, sum(ok)))),
    rmse = sqrt(mean((y[ok] - mu[ok])^2)), mae = mean(abs(y[ok] - mu[ok])))
}

# 二元 Y：AUC（rank 預設用平均名次處理相同預測值，結果正確）與 Brier score
auc <- function(y, p) {
  ok <- !is.na(p); y <- y[ok]; p <- p[ok]
  r <- rank(p); n1 <- sum(y == 1); n0 <- sum(y == 0)
  (sum(r[y == 1]) - n1 * (n1 + 1) / 2) / (n1 * n0)
}

# 校準：把預測機率分成五等份，比較預測平均與實際比例
calib <- function(y, p) {
  data.frame(p = p, y = y) |> subset(!is.na(p)) |>
    transform(bin = cut(p, quantile(p, seq(0, 1, .2)), include.lowest = TRUE)) |>
    dplyr::group_by(bin) |>
    dplyr::summarise(預測平均 = mean(p), 實際比例 = mean(y), n = dplyr::n())
}
```

## E. 讓結論與最終模型一致

1. 在總結之前，先明確寫出：**最終模型是哪一個**（例如 m4），並說明選它的理由。
2. 結論中的所有估計值（係數、odds ratio／rate ratio、信賴區間、p 值）、診斷結果、預測指標，**都必須來自最終模型**。
3. 若最後選擇較複雜的模型（例如 m4），就以 m4 的估計為主要結論，不要沿用較簡單模型（例如 m2）的數字。
4. 若最後保留較簡單的模型（例如 m2），必須清楚說明簡化的目的（例如為了容易解釋），以及它的配適限制（例如概似比檢定顯示 m4 顯著較佳）。
5. **不要混用不同模型的結果而不交代。** 引用其他模型的數字（例如敏感度分析）時，標明是哪個模型、為什麼引用。
6. **整體檢定也必須用最終模型重做。**「用最終模型」不等於固定用同一個檢定函數：要依最終模型的 family、離散參數的處理方式與要檢定的假設選擇方法。 類別變數或多自由度項的整體效果檢定（例如「spray 整體有關聯」），不得沿用候選模型（例如 Poisson 或 quasipoisson）的 LRT 或 F 檢定當作最終結論的依據。做法依最終模型而定：
   - 一般 GLM：`car::Anova(model)`、`drop1(model, test = "Chisq")`（有估計離散參數的 family 用 `test = "F"`）。
   - 負二項（`glm.nb`）：建議把虛無模型也用 `glm.nb` 重配，讓 θ 在兩個模型中各自估計，再比較：`anova(glm.nb(y ~ 1, data = dat), model)`（有其他共變數時，虛無模型保留共變數、只拿掉要檢定的項）。`drop1()` 與 `car::Anova()` 則把 θ 固定在最終模型的估計值，統計量通常較大，結論較樂觀。兩種做法不要混用，報告中寫明用的是哪一種。
7. **寫完結論後，逐句檢核**：
   1. 每個數字是否都來自最終模型？
   2. 每個比較性陳述（較好、最佳、相近）是否都有對應的檢定支持（見 H 的多重比較）？
   3. 有沒有出現因果措辭（本 skill 只描述關聯）？
   4. 「不顯著」有沒有被寫成「相同」或「沒有差異」（見 H）？
   5. 整體檢定是否來自最終模型？
   檢核不通過的句子要改寫，不要留著。

## F. 估計是否成功：收斂、分離與樣本數檢查（每次配適後立即做）

模型能成功輸出 `summary()`，不代表估計一定可靠。每配適一個候選模型，就要檢查：

- 是否有收斂警告，`m$converged` 是否為 `TRUE`。
- 係數是否極端大、標準誤是否異常大（例如好幾千以上）；**即使 `converged` 為 `TRUE`，完全分離時仍可能出現極大的係數與標準誤**。
- 擬合機率是否接近 0 或 1（`glm.fit: fitted probabilities numerically 0 or 1 occurred` 警告）。
- 各候選模型實際使用的觀測數是否一致（`nobs()`），是否因缺失值或無效轉換（如 `log(0)`）導致部分資料被排除。

```r
check_fit <- function(m) {
  co <- summary(m)$coefficients
  data.frame(收斂 = isTRUE(m$converged), 邊界 = isTRUE(m$boundary), 觀測數 = nobs(m),
             最大絕對係數 = max(abs(co[, 1])), 最大標準誤 = max(co[, 2]),
             最大擬合值 = max(fitted(m)), 最小擬合值 = min(fitted(m)))
}
check_fit(model)
```

**完全分離／準完全分離**（logistic 回歸）：最大概似估計不穩定或係數發散。不能只因為模型輸出了係數就照常解釋，要告知使用者，並考慮 Firth 懲罰迴歸等方法；**這些方法超出本 skill 的支援範圍**，要如實說明，並建議合併稀少的類別、檢查是否有某個變數幾乎完全決定 Y，或請使用者使用專門的工具。

**樣本數**：不要用單一的「每個參數 10–20 筆」規則決定能否分析。事件比例、稀有事件、完全分離、參數個數、資料分布與估計方法都會影響穩定性。每個參數所需事件數（EPV）只是粗略的經驗法則，不是模型的准入標準；樣本偏少時要明講估計可能不穩定，並檢查上面幾項。

## G. 缺失值處理與報告

1. 報告各變數的缺失比例。
2. 報告模型**實際使用的樣本數**，以及因缺失值被排除的觀測數（`nobs(model)` 對照原始筆數）。
3. **不得在未說明的情況下**把缺失值當成 0，或直接用平均數填補。
4. 使用完整個案分析（complete-case）時，說明這種處理可能帶來的偏誤。
5. 需要插補時，要考慮研究目的與缺失機制；用於預測驗證時，插補必須在每一折的訓練資料內執行（見 D）。
6. 插補或排除的決定要和使用者確認。

## H. 係數解釋規則

- **類別變數**：說明參照組是什麼，係數是和參照組比較的結果。
- **連續變數**：說明係數對應的增加單位（每增加 1 個單位、1 個標準差，還是 10 個單位）。
- **轉換後的變數**：依轉換後的尺度解釋。例如 `log1p(x)` 的係數不能直接講成 x 增加 1 單位的效果；`log(x)` 在 log link 下常解釋為 x 增加百分之幾對應的相對變化。
- **不確定性**：估計值盡可能搭配信賴區間與 p 值，而不是只報是否顯著。
- **Odds ratio 不是風險比**，也不能直接說成「機率增加幾倍」；事件不罕見時，兩者可能差很多。
- **樣條、多項式或其他非線性形式**：通常不能用單一係數概括整體效果，改以預測值（機率或平均計數）、對比或曲線呈現。
- **交互作用**：主效應的解釋要在交互作用的另一個變數取特定值下說明。
- 以「在其他變數固定下」作為前提，措辭一律用「關聯」，不用因果語氣。

### 類別變數的多重比較

類別變數有三個以上水準時，各組對參照組的係數只回答「和參照組比」。若結論涉及**非參照組之間的比較**，或出現「最好」「最差」「排名」「效果最佳」等措辭，必須用 `emmeans` 做兩兩比較並校正多重比較，報告時寫明校正方法：

```r
library(emmeans)
emm <- emmeans(model, ~ group)                         # 各組的估計邊際平均
pairs(emm, adjust = "tukey", type = "response")        # 兩兩比較；log link 下以比值（ratio）呈現
confint(pairs(emm, adjust = "tukey"), type = "response")   # 校正後的信賴區間
```

- 沒有做兩兩比較時，只能說「點估計以某組最低（最高）」，不得寫成「某組顯著最佳」。
- 比較的是同一個族群中的所有組別時，Tukey 是常見選擇；只和一個對照組比較時可用 Dunnett（`contrast(emm, "trt.vs.ctrl")`）。校正方法要在檢視結果之前先決定。
- 負二項、Poisson、Gamma 等 log link 模型的 `pairs()` 輸出是倍數（ratio），不是差；logit link 則是 odds ratio。

### 「不顯著」不等於「相同」

信賴區間包含 1（比值尺度）或 0（差值尺度），只能寫成「資料無法區分」，不得寫成「效果相近」「沒有差異」「相同」。必要時引用信賴區間的上下限，說明差異可能的範圍；若範圍很寬，要明說樣本不足以排除實質差異。真的要宣稱「等效」，需要事先設定等效界線並做等效性檢定，超出本 skill 的預設範圍。

### 呈現係數表時的陷阱

- `broom::tidy(model, exponentiate = TRUE)` **只轉換 `estimate` 與信賴區間**，`std.error` 和 `statistic` 仍是 link scale（log 或 logit），和轉換後的估計值並排放會誤導讀者。呈現時只保留需要的欄位（`term`、`estimate`、`conf.low`、`conf.high`、`p.value`），或在表格標題明確註明。
- **信賴區間的方法要註明**：`confint(model)` 對 GLM 是 profile likelihood，`confint.default(model)`、`emmeans` 與 `predict(se.fit = TRUE)` 則是 Wald；`broom::tidy(conf.int = TRUE)` 用的是哪一種，以實際版本與模型類別為準，不確定就用 `confint()` 自行計算並註明。同一份報告中係數表與預測表（或兩兩比較）的區間方法不同時，必須說明。
- 表格要含有編號欄（rownames）時，建立 `data.frame` 一律加 `row.names = NULL`，避免輸出出現重複的列名欄。
