# Stage 4 模型診斷檢查清單

## 總原則：診斷指標是證據，不是自動決策規則

下面出現的所有門檻（例如 VIF 大於 5、離散比值大於 1）都只是**警示**，不是判決線。每一項診斷都要結合資料結構、研究目的與其他診斷證據一起解讀；發現問題時，先辨識可能原因、提出處理選項，不要把所有問題一律歸因於同一個假設，也不要看到某個數值超過門檻就自動換模型。換了 family、link 或函數形式之後，要重新配適並重新做相關診斷。

每一項都要跟使用者說「這在檢查什麼、看到的結果怎樣、可能的原因與處理選項」。

## 0. 總覽圖

先用 base R 內建的四合一診斷圖當總覽（不需要額外套件）：

```r
par(mfrow = c(2, 2))
plot(model)
```

畫出 Residuals vs Fitted、Normal Q-Q、Scale-Location、Residuals vs Leverage。**這張總覽圖不能取代依 family 選擇的診斷方法，也不代表四張圖都適用同一套判讀標準**，GLM 的判讀方式如下：

- **Residuals vs Fitted**：尋找系統性趨勢、曲線或未被模型捕捉的結構。
- **Normal Q-Q**：GLM **不要求**原始殘差或 deviance residuals 服從常態，所以不能用它判定「誤差是否常態」。只用來觀察有沒有極端偏離或異常點。
- **Scale-Location**：觀察殘差散布有沒有異常型態，但不要直接套用線性迴歸的等變異假設（GLM 的變異本來就可能隨平均數改變）。
- **Residuals vs Leverage**：只觀察有沒有觀測值的槓桿明顯偏高，僅供參考，不據此自動刪除資料。

二元 logistic 模型的殘差圖本來就會呈現分層或條帶狀，那是資料型態造成的，不一定代表模型有錯。

**使用這張總覽圖的規則**：
- R 對 GLM 物件使用的是 `plot.lm()` 的方法，圖形與殘差的定義和線性迴歸的診斷圖不完全相同，**不保證對所有 GLM 都產生下面這四張圖**。
- 先確認實際產生了哪些圖（不同模型類別或 family 的預設圖可能不同），再逐張解釋，不套用固定的判讀標準。
- 不要把 Q-Q 圖解讀成 GLM 誤差常態性的檢定；GLM 的殘差分布依 family 而定，不是常態。
- 依 family 另外做適用的診斷：分布假設、過度離散、校準，或 DHARMa 模擬殘差。
- 某張圖不適用於目前模型時，明確說「這張圖不適用，原因是……」，不要硬套判讀。

**注意**：`performance::check_model()` 的畫圖功能需要額外的 `see` 套件，不一定裝得到，若 `library(see)` 失敗就改用上面的 `plot(model)`。`performance::check_overdispersion()`、`car::vif()` 這類純文字或數值輸出的函式不受影響。

## 1. 殘差診斷

GLM 不能直接看原始殘差，常用兩種：

```r
res_p <- residuals(model, type = "pearson")   # 對變異數標準化，適合看變異結構
res_d <- residuals(model, type = "deviance")  # 概似函數角度的殘差
dat$fitted <- fitted(model)
dat$res_d <- res_d
ggplot(dat, aes(fitted, res_d)) +
  geom_point() + geom_hline(yintercept = 0) +
  labs(x = "Fitted", y = "Deviance residual")
```

重點：殘差有沒有隨 fitted values 呈現系統性的曲線趨勢（可能 link 不合適、遺漏變數，或模型未捕捉非線性關係），以及散布是否異常。**只畫殘差對 fitted values 不夠**，還要把殘差對每個重要的連續解釋變數作圖（可加平滑線），找未被模型捕捉的非線性（只在報告中描述，不自動加入非線性項）。若資料有時間、空間或群聚結構，要依資料設計另外檢查相依性（例如殘差對時間順序作圖、自相關檢查、依群組看殘差的平均）。殘差圖沒有明顯型態，不代表所有模型假設都成立。

## 2. 過度離散（overdispersion）

過度離散是指資料變異比模型所假設的大，會讓標準誤被低估。**要依資料形式解讀，不要把某個離散比值當成統一的判定標準。**

```r
performance::check_overdispersion(model)            # 主要適用 poisson／負二項等計數模型
sum(residuals(model, type = "pearson")^2) / df.residual(model)   # 手算 Pearson 離散比值
```

- **poisson／計數資料**：比值明顯大於 1 是警示（不訂固定的 1.5 或 2 當門檻）。應同時看估計值、檢定結果、殘差型態與研究設計，並考慮是不是平均數結構設定不對、遺漏變數、離群值、零值過多或觀測相依造成的，而不是直接換 family。
- **單筆 0/1 的 binomial**：每筆只有一次 Bernoulli 試驗，其變異完全由平均數決定，**沒有可獨立估計的額外離散參數**，不能把一般的二元變異當成過度離散，也不要對它做過度離散檢定並據以換模型。**但這不代表單筆二元資料沒有配適問題**，仍要檢查：(1) 平均數結構是否合理（有沒有遺漏非線性或交互作用）；(2) 是否有群聚、重複測量或其他相依性（相依性會讓標準誤失真，卻不會表現成離散比值）；(3) 預測機率與實際比例的校準；(4) 有無分離問題。
- **分組 binomial（`cbind(success, failure)`）**：可能有額外的組間異質性，離散檢查有意義，此時 `quasibinomial` 是一個可考慮的選項。
- **補救的限制**：`quasipoisson`／`quasibinomial` 只調整離散程度對標準誤的影響，**不會**自動修正錯誤的平均數結構、遺漏變數、觀測相依，或其他形式的模型錯置。`MASS::glm.nb()` 採用不同的條件變異數結構，與 quasi 不是等價的替代方案。換模型後要重新檢查殘差與配適。
- **換模型後的診斷不是獨立驗證**：負二項的 θ 是用同一批資料估計、專門用來吸收多出的變異，所以換成負二項後離散比值接近 1、Pearson 適合度檢定不顯著，**並不意外**，但負二項不保證離散比值一定接近 1（仍受平均數模型是否適當、資料結構、樣本量與 θ 估計的影響），也不能據此認定負二項已充分配適，更不是「模型確實正確」的強力證據。報告時只能說「θ 已吸收多出的變異」，並搭配殘差型態、平均數結構檢查與預測評估一起判讀。
- **同一個統計量不重複算成兩份證據**：先確認各診斷函數實際使用的統計量與參考分布。對一般 Poisson GLM，`performance::check_overdispersion()` 通常以 Pearson 殘差平方和為基礎，與手算的 Pearson 離散比值或 Pearson 卡方檢定是同一項證據，不應重複計為獨立證據；若函數使用不同的方法（例如模擬式診斷、不同模型類別的實作），則是不同證據，要說明差異。不確定時查函數說明文件，不要憑印象下結論。
- **負二項的自由度**：θ 是由資料估計的離散參數，但它不是迴歸係數，`df.residual(model)` 是觀測數減去模型矩陣的秩，**不會**因估計了 θ 就自動扣掉任何數值，**也不能寫成「自由度要扣掉 θ 的數值」**。以 Pearson 卡方統計量做適合度檢定時，要確認所採用方法的自由度是否考慮了 θ 的估計；不可直接把 `df.residual` 當成已扣除所有估計參數後的通用適合度檢定自由度。θ 的估計不確定性也會讓卡方近似不夠精確，所以負二項的 Pearson 離散比值與檢定只當粗略參考，不要過度解讀小數點差異。
- **較獨立的檢查（選用）**：若環境裝得到 `DHARMa`，可用模擬殘差作為補充，它對各種 family 都用同一套邏輯，不依賴 Pearson 統計量：

```r
sim <- DHARMa::simulateResiduals(model)
DHARMa::testDispersion(sim)       # 離散程度
DHARMa::testUniformity(sim)       # 殘差分布是否均勻（整體配適）
plot(sim)
```

裝不到 DHARMa 時就略過，不要因此假裝做過這項檢查。

## 3. 共線性（multicollinearity）

```r
v <- car::vif(model)
v
```

- VIF 衡量係數變異被其他解釋變數膨脹的程度。常見的經驗警示是大於 5 或 10，但這**不是自動刪除變數的規則**。
- 若某個變數是研究問題的核心暴露或重要的混雜因子，即使 VIF 偏高也可能必須保留。
- **含多個水準的類別變數等多自由度項時**，`car::vif()` 會回報廣義 VIF（GVIF），輸出會多出 `Df` 與 `GVIF^(1/(2*Df))` 欄位。不能直接把 GVIF 拿去和 5 或 10 比較，要看調整後的 `GVIF^(1/(2*Df))`（它的尺度相當於 VIF 的平方根，所以把它平方後，才大致可與 VIF 的經驗警示比較）。
- 處理順序：先檢查變數是不是重複表達同一個概念、是否為結構性共線性（例如同時放入某變數與它的平方，或啞變數陷阱），再依研究目的決定處理。可行的處理包括合併概念相同的變數、重新定義變數（例如置中）、保留核心變數並說明限制。
- 若係數的標準誤很大、信賴區間很寬或符號不穩定，要看係數估計、信賴區間與敏感度分析，而不是只報一個 VIF 數字。
- 本 skill 的目的是解釋係數，共線性會讓係數估計不穩定、信賴區間變寬；共線性對預測表現的影響通常較小，必要時一併說明。
- VIF 只描述解釋變數之間的重疊程度，**不是模型整體是否適當的指標**，也不應只因 VIF 偏高就自動刪除具有研究意義的變數。

## 4. 適合度檢定（goodness-of-fit）

```r
pchisq(deviance(model), df.residual(model), lower.tail = FALSE)   # 僅適用於條件允許的分組資料
```

- **分組 binomial／計數資料**：deviance 或 Pearson 卡方的近似需要足夠的條件（每組的預期成功與失敗次數、計數不能太小，分組結構合適）。資料稀疏時近似可能不可靠，即使得到很小的 p 值，也要先確認檢定的適用條件，再下結論說模型配適不佳。
- **單筆（未分組）二元資料**：Pearson 卡方或 deviance 的參考分布通常不可靠，**不要**把它們當成標準的適合度檢定。應改看校準（預測機率與實際比例是否一致）、殘差型態、模型結構，以及適當的預測評估（見 `model-building-and-validation.md` 的 D 節）。
- **一般性規則**：正式適合度檢定的參考分布與 p 值解讀，必須符合該檢定的資料結構與漸近近似條件（樣本大小、分組方式、觀測獨立性、估計參數個數與剩餘自由度、預期頻數）。即使每組預期成功與失敗次數看起來足夠，也不能單憑這一點保證卡方近似可靠；若條件不充分，應將檢定結果視為有限的診斷證據，搭配其他方法判讀。
- **「不顯著」的意義**：檢定不顯著只表示沒有足夠證據拒絕該模型假設，**不能證明模型正確**，特別是小樣本時檢定力不足。報告時不要寫成「模型配適良好已獲證實」。
- 可輔助參考：巢狀模型比較（`anova(m0, m1, test = "Chisq")`），以及 `performance::r2(model)` 的 pseudo-R²，但要說明 pseudo-R² 不能像 OLS 的 R² 那樣解釋成「解釋變異的比例」。

## 5. 模型比較與最終模型的確認

候選模型的系統性比較、選模原則，以及診斷與樣本外預測評估的區分，詳見 `model-building-and-validation.md` 的 C、D 節。

**預設只有一個模型（m1），先對它做診斷。** 診斷發現問題時，才提出調整後的模型（m2），重新配適並做同一套診斷（離散程度、殘差型態），再比較 m1 與 m2 並確認最終模型；沒有發現問題，m1 就是最終模型。使用者要求比較多個模型時，則對主要候選模型並排做同一套診斷。報告中依序說明「m1 → 診斷發現 → 調整為 m2 → 比較 → 確認」，不要寫出順序倒置的句子。

- 巢狀模型：概似比檢定 `anova(reduced, full, test = "Chisq")`（有估計離散參數的 family，例如 Gamma 或 gaussian，用 `test = "F"`）。
- 非巢狀或需要權衡複雜度時：`AIC()`／`BIC()`，且必須在**相同的分析樣本**上比較。
- `quasipoisson`／`quasibinomial` 沒有概似函數，不能用一般的 AIC 或標準概似比檢定。

## 6. 計數資料中的零值（只做評估與概念說明）

比較「實際的 0 個數」與「模型預期的 0 個數」，並評估差異的大小與不確定性，再決定是否需要進一步分析。**不使用固定的百分比（例如多出一成）當判定門檻**，因為相同的差距在小樣本與大樣本的意義不同，預期的 0 也受估計模型、解釋變數與條件平均數影響。

```r
# poisson 模型預期的 0 個數（負二項改用 dnbinom(0, mu = fitted(model), size = model$theta)）
p0 <- dpois(0, lambda = fitted(model))
obs0 <- sum(dat$y == 0)
exp0 <- sum(p0)
sd0  <- sqrt(sum(p0 * (1 - p0)))      # 抽樣變異的粗略估計，未計入係數的估計不確定性
c(實際 = obs0, 預期 = round(exp0, 1), 差距 = round(obs0 - exp0, 1), 差距的粗略標準差 = round(sd0, 1))
```

零值多出預期，不一定代表零膨脹，也可能是：

- 平均數模型設定不正確
- 解釋變數不足或未建模的異質性
- 過度離散（先處理過度離散，再判斷零值是否仍然過多）
- 資料的觀察機制或抽樣方式特殊

**流程**：觀察到零值比預期多時，**先評估上面這些替代解釋，不可直接判定為零膨脹**。只有在替代解釋都處理過（或無法合理解釋）、零值仍明顯偏多時，才向使用者說明兩種延伸模型怎麼區分（要看資料的產生機制，不能只看 AIC）。兩者機制不同，不能視為同一種模型，也不是每一種計數資料都適用門檻模型：

- **零膨脹模型（zero-inflated model）**：0 可能來自兩種機制。一種是結構性 0，例如不具備發生事件條件的個體；另一種是計數過程產生的 0，例如具備發生條件，但觀察期間內剛好沒有事件發生。
- **門檻模型（hurdle model）**：將資料生成過程分成兩個階段。第一階段決定觀察值是否為 0；第二階段在觀察值大於 0 的條件下，使用排除 0 的截斷計數分布來描述正計數的大小。

**範圍限制（務必告知使用者）**：本 skill 不支援零膨脹與門檻模型的配適、診斷與係數解釋。判斷並說明上述區別之後就停止，請使用者改用專門的工具處理，不要自行延伸分析。

## 診斷完成紀錄（Stage 4 結束前必做）

不要只說「已讀取診斷清單」或「診斷完成」就假設每項都做了。Stage 4 結束前，列一張表，對每一項檢查記錄它的狀態，避免把「沒發現問題」「檢查不適用」「根本沒執行」混為一談：

| 狀態 | 意義 |
|---|---|
| 已執行，結果可判讀 | 檢查已跑完，結果能支持結論 |
| 已執行，結果受限 | 跑了但有限制（例如卡方近似條件不足、樣本太小、套件版本差異），要寫明限制 |
| 不適用，已跳過 | 因資料結構不適用（例如單筆二元資料的過度離散檢定），要寫明原因 |
| 無法執行 | 缺少套件、資料或環境限制（例如 DHARMa 裝不到），要如實說明 |

表格欄位：檢查項目、狀態、結果摘要或原因。報告檔案中也要放這張表。

## 常見問題與可能的處理方向

| 診斷發現 | 可能原因（先辨識，不要只歸咎一項） | 處理選項 |
|---|---|---|
| 計數資料離散比值偏高 | 平均數結構錯置、遺漏變數、離群值、零值多、觀測相依、真正的過度離散 | 先檢查模型設定與資料，再考慮 quasipoisson 或 glm.nb，換模型後重新診斷 |
| 計數資料實際的 0 多於預期 | 過度離散、模型設定不對、0 有兩種來源或需跨門檻 | 評估差距大小與不確定性；必要時說明零膨脹與門檻的區別，之後本 skill 不支援 |
| 殘差對 fitted 呈系統性曲線 | link 不合適、遺漏變數、模型未捕捉非線性關係 | 檢查 link 與遺漏變數；若是非線性，在報告中描述並列為延伸討論，不自動加入非線性項 |
| VIF 或 GVIF 偏高 | 變數重複表達同一概念、結構性共線性 | 先檢查概念與結構，再依研究目的處理，不自動刪除 |
| 分組 binomial 的 goodness-of-fit p 值很小 | 配適不佳，或近似條件不足 | 先確認檢定適用條件，再檢查遺漏變數與交互作用 |

## 給使用者的說明範例語氣

「我們檢查了離散程度，Pearson 離散比值約 2.3，高於 1，是過度離散的警示。這可能是資料真的比 Poisson 假設的更分散，也可能是模型漏了重要變數或函數形式不對造成的，所以我先檢查了殘差與連續變數的形式，沒有發現明顯的結構問題。因此接下來把負二項模型加入候選，重新配適並重新檢查殘差，再依事先講好的選模原則比較。」
